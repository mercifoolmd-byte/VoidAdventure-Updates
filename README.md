# Void Adventure - Closed Alpha

This repository is used exclusively for the auto-updater.
Do not edit these files unless you are pushing a new game build.

## Download the Game
To play, download the initial build here:
[Download v1.0.0 (Google Drive)](https://drive.google.com/file/d/1qUN0Xnn79qOj4KzGZv6qd_yw42K82Jmq/view?usp=drive_link)

## How to Update
Once you have the game installed, it will automatically check for updates when you launch it. You don't need to redownload from Google Drive again.
